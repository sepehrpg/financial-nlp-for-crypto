# الزامات Financial NLP

در طراحی پروژه این اصول را رعایت کن:

1. Sentiment را برابر Market Impact در نظر نگیر.
2. اخبار تکراری و بازنشرشده را کنترل کن.
3. Timestampها را به UTC تبدیل کن.
4. تفاوت `published_at`، `first_seen_at` و `crawled_at` را در نظر بگیر.
5. از داده آینده در Featureهای گذشته استفاده نکن.
6. برای داده زمانی از Random Split استفاده نکن.
7. تمام نسخه‌های یک خبر یا Event را در یک Split قرار بده.
8. TF-IDF، Scaler، PCA و Feature selector فقط روی Train آموزش ببینند.
9. Thresholdها فقط با Validation انتخاب شوند.
10. Test set تا پایان پروژه دست‌نخورده باقی بماند.
11. اگر Labelها توسط LLM ساخته شده‌اند، آن‌ها را Gold Label قطعی در نظر نگیر.
12. محدودیت نسبت‌دادن حرکت قیمت به یک خبر را گزارش کن.
13. برای اخبار هم‌زمان، Duplicate detection و Event clustering را در نظر بگیر.
